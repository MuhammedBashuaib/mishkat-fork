Printed Mushaf layout and Hafs display text

The bundled printed-mushaf.json is generated from the Quranic Universal
Library (QUL), developed by Tarteel, using its published QPC V2 (1421H)
15-line layout and KFGQPC Hafs word-by-word Unicode text exports.

Quran script and Madinah Mushaf source:
King Fahd Glorious Quran Printing Complex (KFGQPC), Al-Madinah, Saudi Arabia.
https://qurancomplex.gov.sa/

Layout organisation and word-by-word exports:
Quranic Universal Library (QUL) / Tarteel.
https://qul.tarteel.ai/resources/mushaf-layout/10
https://qul.tarteel.ai/resources/quran-script/312

The two SQLite exports were obtained from this published mirror at a pinned
revision, not from Quran Foundation API responses:

them to the application's existing canonical recitation word identities.
